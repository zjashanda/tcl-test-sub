# TCLTestSub 能力矩阵

## 成熟度

- **已实现且有真实证据**：有执行入口、结构化结果和真实设备日志。
- **辅助验证**：可用于覆盖或定位问题，但不是独立长稳场景。
- **部分覆盖**：只覆盖需求的一部分。
- **仅需求**：只记录在 `doc/压测列表.txt`，尚无自动化入口。
